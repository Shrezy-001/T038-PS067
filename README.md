# PS-067 — University Exam Timetabling and Hall Allocation Engine

A Python-based backend system for automating university examination scheduling, hall allocation, student seating, invigilator assignment and examination rescheduling.

## Project Information

- **Project ID:** PS-067
- **Domain:** Education – University Examinations
- **Difficulty:** High
- **Language:** Python 3.10+

## Key Features

- Automated examination timetable generation
- Student examination clash detection
- Programme-semester gap management
- Examination hall allocation
- Student seating and seat number generation
- Special-needs accommodation
- Invigilator allocation and workload management
- Late student registration
- Examination postponement
- Hall unavailability management
- Violation reporting
